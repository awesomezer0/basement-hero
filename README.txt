ПОДВАЛЬНЫЙ ГЕРОЙ — установка на телефон

Что внутри: index.html (игра), manifest.webmanifest и sw.js (установка и офлайн), папка icons.
Файлы нужно выложить на любой бесплатный хостинг с https, например GitHub Pages или Netlify.
Потом открыть адрес на телефоне и добавить на главный экран.

Если меняешь игру, увеличь число VER в начале sw.js (v1 -> v2), иначе телефон покажет старую версию.
Прогресс хранится только на телефоне. Раз в неделю делай «Сохранить копию» в настройках игры.
